# ESM-ECForest
A two-stage ESM-2 and Random Forest framework for hierarchical enzyme annotation.

## Overview
ESM-ECForest combines:
- ESM-2 protein language model embeddings
- Random Forest classification
- Two-stage prediction workflow
- Hierarchical EC annotation

The workflow consists of:
1. Enzyme / non-enzyme classification
2. Hierarchical EC number prediction

## Features
- Enzyme / non-enzyme classification
- Hierarchical EC prediction
- ESM-2 embeddings
- Random Forest classifier
